PROJECT TITLE
AgentScout — Autonomous AI Job Research Agent

PROJECT DESCRIPTION
AgentScout is an agentic AI application that helps users discover and prioritize current job opportunities. It converts a user's target role, location, skills, experience level, and work-mode preferences into a live web research task, uses Anakin to search and read web information, evaluates the returned evidence, ranks opportunities against the user's requirements, and provides direct action links. The project is built with Python, Streamlit, the official Anakin Python SDK, and the Anakin Search API.

EXPLAIN IN DETAIL WHERE YOU USED ANAKIN
Anakin is the live-web intelligence layer of AgentScout. The application uses the official Anakin Python SDK to send a structured research objective to Anakin's Search API. Anakin performs the live web search and returns structured web evidence such as titles, URLs and relevant text. AgentScout then reads that evidence, evaluates it against the user's job preferences, calculates a match score, ranks the results, and presents the highest-priority opportunities with direct source/application links. This makes Anakin part of the core agent workflow rather than being used only for a chatbot-style response.

TECH STACK
Python, Streamlit, Anakin Python SDK, Anakin Search API, python-dotenv

PROJECT FLOW
User requirements → AgentScout research prompt → Anakin live-web search → Web evidence → Preference-based scoring → Ranked recommendations → Direct action links
